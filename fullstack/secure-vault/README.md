# SecureVault Dashboard — Enterprise File Explorer Engine

SecureVault is a high-performance, cyber-secure, and fast digital asset management interface engineered specifically for the strict nested-file storage needs of enterprise law firms and banking institutions. Built to replace legacy data layouts, this solution combines high-fidelity visual design paradigms with optimized recursive computer science fundamentals.

## 🛠️ Core Capabilities & Architecture

### 1. The Recursive Tree Engine (Story 1 & 2)
The application architecture relies on an immutable React state system context that parses hierarchical structures dynamically using a deep object-mapping component strategy. The system sources its structural configuration directly from `src/data/data.json`. The data layer models tree nodes cleanly without breaking visual continuity, regardless of whether the directory tree depth spans 2 levels or 20 levels. Folders expand and collapse locally using optimized node identity keys.

### 2. High-Contrast Terminal Typography & Palette
To maintain a precise, cyber-secure workspace aesthetic, our tailored theme leverages:
* **UI Typography:** `Plus Jakarta Sans` for clean, readable administrative structural headers.
* **Metadata & Telemetry Typography:** `JetBrains Mono` for cryptographic hash checks, tracking identifiers, file extensions, and timestamps.
* **Color Hierarchy:** Deep `#0B0F17` canvas profiles accented by neon responsive states (`#00E5FF`).

### 3. Keyboard Accessibility Matrix (Story 3)
A native React event hook captures keyboard inputs to provide full structural navigation without touch peripherals:
* `ArrowUp` / `ArrowDown`: Glides smoothly across visible rows in the folder tree layout.
* `ArrowRight`: Expands highlighted folder nodes to reveal inner sub-trees.
* `ArrowLeft`: Collapses the selected folder directory branch.
* `Enter`: Commits deep node focus, instantaneously populating data fields into the right-hand **Properties Panel**.

### 4. The Wildcard Feature: Adaptive View Engine (Story 4)
* **The Identified Gap:** While legal analysts navigate large data hierarchies in structural lists, compliance officers routinely perform rapid validation passes where abstract grid cards are more efficient.
* **The Business Innovation Solution:** We implemented an **Adaptive View State Engine** that allows users to seamlessly switch between a dense, tabulated List View and a high-fidelity Grid View Card configuration. This enhancement dramatically reduces operational friction for power users operating on compact terminal setups.

### 5. Advanced Telemetry Search Bar (Story 5)
Features a real-time regex filtering mask that crawls structural tree levels. Typing inside the engine isolates matches and triggers a recursive auto-expansion script on nested parental nodes, ensuring targets deep within the directory structure are exposed immediately.

## 📦 Local Installation & Setup

Ensure you have [Node.js](https://nodejs.org/) installed locally before configuring the development terminal environment.

1. **Clone the Repository Fork:**
   ```bash
   git clone [https://github.com/OdileMas/SecureVault-Dashboard.git](https://github.com/OdileMas/SecureVault-Dashboard.git)
   cd SecureVault-Dashboard/fullstack/secure-vault

2. Install Required Package Environments:

Bash
npm install

3. Launch the Local Development Server:

Bash
npm run dev
